Object types — the eight nodes on the workflow map
Source
Raw, unstructured input entering the workflow from the left.
Reference
Reusable policy, config, or threshold that governs steps.
Artifact
A structured signal object — the unit of workflow progress.
Process
A transformation step that operates on one or more artifacts.
Decision
A branch or fork — sign-off or escalation determines the path.
Handoff
Human-in-the-loop routing; captures a response and routes forward.
Output
The delivered business result — the morning brief.
Archive
Retention and delivery record; seeds tomorrow's run. Often locked.
Signal-flow primitives — conceptual layer (no CSS tokens; documented only)
Raw signal
Unstructured input entering the workflow. Not yet extracted or normalized. Lives in a source node.
Extracted signal
A field or value pulled from a raw source and normalized into a usable form.
Trusted artifact
A structured object that passed validation. Safe to reuse downstream without rebuilding.
Reuse path
A downstream node consuming a trusted artifact without rebuilding the upstream work.
Needs inputs
A node that can start once an upstream artifact exists. Blocked until inputs arrive.
Governance signal
A policy, config, or threshold that controls workflow behavior. Usually a reference node.
Operational source of truthconceptual
An artifact designated as the authoritative record that downstream systems trust.
Audit / provenanceconceptual
The record of who built what artifact, when, and from which upstream inputs.
